# ShaneOS

Local-first entertainment control system for Shane's living room.

## Goals
- One interface for TV, AVR, PC, lights, media, and future devices
- Works on the local network even if internet access is down
- UI and device-control logic stay separate so either can evolve independently
- Designed first for a Samsung Galaxy Tab S3 in landscape

## v0.1
This first build is a front-end prototype with simulated device state. Real hardware integrations will be added as the router, BroadLink RM4 Pro, LED controllers, NAS/media server, and other components come online.
